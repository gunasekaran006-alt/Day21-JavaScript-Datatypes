# JavaScript Data Types - Day 21 Practice 🚀

This repository contains my day 21 practice on **JavaScript Data Types**. It covers the fundamental concepts of how data is stored and manipulated in JavaScript, including both Primitive and Reference types.

## 📌 Concepts Covered

### 1. Primitive Data Types
Simple data types that are stored directly in the location that the variable accesses.
- **String:** Textual data (e.g., `"Narasimhan"`).
- **Number:** Integer and floating-point numbers (e.g., `26`).
- **Boolean:** Logical entities (`true` or `false`).
- **Undefined:** A variable that has been declared but not assigned a value.
- **BigInt:** For numbers larger than the maximum safe integer limit.

### 2. Reference Data Types (Non-Primitive)
Objects that are stored by reference in memory.
- **Arrays:** Used to store multiple values in a single variable (e.g., `skills`).
- **Objects:** Key-value pairs representing a real-world entity (e.g., `userProfile`).
- **Functions:** Reusable blocks of code (e.g., `welcome()`).
